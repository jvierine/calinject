# JLC complete-assembly upload

Upload BOM.xlsx and CPL.xlsx together. Each has one worksheet. Generated by
`node tools/bom.mjs --jlc`; the original SMT-only CPL remains unchanged.

95 placements include 81 SMT parts and all manual assembly materials. No customer
soldering is permitted. Unmatched parts require sourcing review, not omission.
The two shunts require a matching closed-top 2.54 mm part proposed by the assembler.

Assembly aliases below are material placements on existing native footprints;
they are not additional electrical components or new PCB footprints.

| Alias | Native footprint / installation |
|---|---|
| U1_HL, U1_HR | U1 left/right 1x9 headers, Harwin M20-9990946 |
| U1_HB | U1 bottom 1x5 header, Harwin M20-9990546 |
| JP1_A, JP1_B | JP1 upper/lower 1x3 headers, Amphenol 68000-103HLF |
| JP1_S1, JP1_S2 | JP1 shunts across pads 1–2 and 4–5, LOW range |

Coordinates are millimetres, X right and Y up, viewed from top, using the native
PCB origin. Header rotation denotes the row axis (0 horizontal, 90 vertical).
Factory must review manual placements against the native PCB and ASSEMBLY.md,
including pin 1, header height and module USB orientation. These assembly aliases
must not be treated as independent SMT placements during automated assembly.

This upload is for a quote. Firmware loading, function testing and first-article
RF/timing qualification remain subject to explicit factory capability review.
